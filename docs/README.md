# Documentation

The documentation here covers the code first. Historical notes, research writeups and source datasheets are kept under `docs/archive/`, separate from the library and tool documentation.

[`library.md`](library.md) covers the C library, its calibration and replay tools, and the Arduino examples. [`hardware.md`](hardware.md) describes the sensor interface (the DFRobot SEN0189 adapter, and bare wiring). [`test-solutions.md`](test-solutions.md) covers the kaolin and diluent used on the bench. Bench procedures are in `docs/bench/`, starting with [`session-1.md`](bench/session-1.md). Its results are in [`session-1-results.md`](bench/session-1-results.md).
