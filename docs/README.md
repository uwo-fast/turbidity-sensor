# Documentation

The current project surface is intentionally code-first. Historical notes, research writeups, and source datasheets were preserved and moved under `docs/archive/` so they remain available without crowding the library and tooling entry points.

[`hardware.md`](hardware.md) describes the sensor interface (the DFRobot SEN0189 adapter, and bare wiring). Bench procedures live under `docs/bench/`, starting with [`session-1.md`](bench/session-1.md).
