# Datasheets and standards

The vendor datasheets and EPA 180.1 are kept here. Two turbidity standards this project refers to
are published under terms that forbid reposting them, so they are cited instead; buy them from
their publishers:

- ISO 7027-1:2016, *Water quality — Determination of turbidity — Part 1: Quantitative methods*.
  International Organization for Standardization.
- BS EN ISO 7027-1:2016, the same standard as adopted by the British Standards Institution.
