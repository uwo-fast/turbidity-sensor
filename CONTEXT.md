# Context

This document provides context for the project, including its purpose, goals, and any relevant background information.

## Purpose

The purpose of this project is to develop a complete firmware and operational manual for the TSW-10 and TST-10 turbidity sensors [or other technically similar sensors]. This will enable users to effectively utilize these sensors for measuring turbidity in various applications.

## Goals

1. Develop a simple, portable firmware that can be easily deployed on an embedded target, such as an Arduino or Raspberry Pi, to interface with the TSW-10 and TST-10 turbidity sensors [with the relevant conditioning circuitry].
